Where AI is called (and where it isn't)

Today's system has two hot AI paths (run on every verification) and two cold paths (fallback only). Tomorrow's system adds vision and adapter authoring.

StageTodayTomorrowWhy AI here
Selector matching Deterministic Deterministic CSS selectors are cheap and fast. AI would be overkill.
Selector miss / DOM drift Claude Opus · HTML extract + Opus vision (screenshot) When CSS misses, an LLM can read the HTML or look at the rendered page and pull the field.
Disambiguation tiebreak Scored deterministic + Haiku tiebreak before HITL If two candidates score within 0.1 of each other, ask a fast LLM before paging a human.
Expiration comparison Claude Haiku Claude Haiku Date formats vary (June 15, 2026 vs 2026-06-15 vs 06/15/2026). LLM classifier handles them robustly.
New-state adapter authoring Manual Claude generates initial YAML Engineer reviews and ships. ~30 min instead of ~2 hours per state.
Anomaly detection on the ledger Threshold rules Claude weekly digest "30% of WA verifications mismatched this week" — surface narratives, not just numbers.

The 50-state routing model

One workflow engine. One profile parser. Fifty YAML configs. The agent's state decides which config gets loaded — the engine code never branches per state.

What lives in a state YAML

One file per state. Selectors are lists (multi-fallback). Tier is a single key. Disambiguation rule is declared, not coded.

state_code: WA version: v2 anti_bot_tier: T2 dre: search_url: https://professions.dol.wa.gov/s/license-lookup flow: multi_page_detail disambiguation_required: true selectors: license_input_label: License Number license_input: - input#License_Number - lightning-input[data-label*='License'] input detail_link_in_row: - td:first-child a detail_expiration: - text=/Expiration Date:?\s*([A-Za-z]+ \d{1,2},? \d{4})/i

Tier escalation (per state, automatic)

The router watches each state's success rate. After 3 consecutive failures it bumps the state up a tier. After 3 consecutive successes at the higher tier it bumps back down.

Why this shape

Determinism first
Selectors do 95% of the work
CSS is cheap, fast, and audit-friendly. The AI bill stays bounded.
AI on fallback
Called when selectors miss
Same workflow code path — no branching between "cheap" and "smart."
Data, not code
50 YAMLs, 1 engine
New state ≈ new YAML. Site redesign ≈ version bump under a flag.
